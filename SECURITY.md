# Security policy

These are local defensive-learning tools, not production security products.

- Do not expose the unauthenticated development dashboards beyond localhost.
- Use only log sources, machines and datasets you own or are authorized to monitor.
- Redact personal data before publishing logs, screenshots or test fixtures.
- Do not add automatic containment or destructive response actions without a separate threat model and review.
- Report suspected project bugs privately to the repository maintainer before public disclosure.
